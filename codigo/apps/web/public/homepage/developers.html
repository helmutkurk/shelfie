Repository

The code is public: https://github.com/helmutkurk/shelfie. Day-to-day work happens on a development branch; main is the release branch.

Design documents are in diseno/ (architecture, contracts, verifier rules, decisions), decision records in docs/adr/, facts checked during the build in codigo/docs/verified.md, and receipts in codigo/docs/evidence/.

Stack

  • TypeScript monorepo with npm workspaces, on Node 24.
  • Engine on Express. The verifier is an x402 Express seller.
  • Web app in React, built with Vite.
  • Shell: a fork of the Masumi hackathon starter, in plain JavaScript.
  • Cardano access through @x402/* 2.26.0 and @evolution-sdk/evolution 0.5.14.
  • Vitest, ESLint, Prettier.
  • Vercel for the web app, a Cloudflare tunnel for the engine, Google Gemini for vision.

API

These routes exist in the code today. The engine is not a public API: the order routes need an access code and are rate limited and capped because they spend Shelfie's credits.

Engine and verifier routes
RouteAccessPurpose
GET /api/healthPublicHealth check
GET /api/config, /api/catalog, /api/tasks, /api/jobs, /api/payouts, /api/ledgerPublic readsConfiguration, catalog, tasks, jobs, payouts and the evidence ledger
POST /api/tasks/:taskId/claim, POST /api/tasks/:taskId/submissionsChecker flowClaim a task, submit a photo
GET /api/orders, POST /api/ordersHeader X-Brand-Token; Idempotency-Key on POSTBrand orders; rate limited and capped
POST /v1/verify (verifier)x402, 1 test ADAVerify one photo
GET /health (verifier)PublicHealth check

Routes used only by the shell or by operators (job creation, settlement events, /api/admin/*) are not documented here.

Run locally

Local runs use fakes: no money, no network calls to Cardano. From the codigo/ folder, with Node 24:

npm ci
npm run check

Then start the three apps in separate terminals:

FAKE_PAYMENTS=1 VERIFIER_PAYMENT=off npm run start -w @shelfie/engine
VERIFIER_PAYMENT=off VERIFIER_MODE=stub npm run start -w @shelfie/verifier
npm run dev -w @shelfie/web

The web app is at http://127.0.0.1:5173/w (checkers) and /dashboard (brands). For a smoke test run npm run hub-up -- --fake, then npm run smoke. Never commit a .env file; the example file contains names only.
