How we built it

The window ran from Friday 2026-10-30, 09:00 to Saturday 2026-10-31, 15:00 (the Devfolio deadline). Preparation before Friday 09:00 was documents and configuration only; the code was written during the event, on top of the organisers' starter templates.

Working with AI agents

Each team member worked with a coding agent (Claude Code or Codex) under one shared rule file, AGENTS.md, and a mandatory context check before any change.

  • Peer review. Everyone pushed to one development branch, and each person's agent reviewed the commits of the others. main changes only through a release pull request with three approvals.
  • ADRs. Design and repository decisions are written as architecture decision records.
  • Facts checked against reality go into a verified-facts file; every session is logged in docs/ai-log.md with what was done, what is open and the handoff.
  • Review of claims. A technical review in the last hours checked each pitch claim against the code and corrected several.
