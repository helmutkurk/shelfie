# Evidence index

Every milestone ends with its evidence saved here (repo-layout section 5). Public data only: tx hashes, explorer links, public wallet addresses, screenshots without secrets.

| Path | What |
|---|---|
| [tx-hashes.md](tx-hashes.md) | One line per milestone transaction |
| `wallets.md` | Public wallet addresses (create at M1) |
| `screenshots/` | Explorer pages, dashboard, terminals |
| ledger snapshots | Copies of the evidence ledger at milestones |

Do not commit mnemonics, keys, `.env`, or photos with people. Do not label a demo override or a fake run as real evidence.
