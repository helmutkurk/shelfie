# CLAUDE CODE — Official Shelfie brand, logo and themes

Use `01_branding/logo_D_approved_original.png` as the **approved reference**. It shows the earth, shopping cart with motion lines, green map pin, two green cubes connected **only by two subtly interlocking oval chain links between the cubes**, and a friendly small robot head as the dot over "i" in "Shelfie", on warm beige/cream. All earlier diamond-link and extra-chain proposals are rejected. Preserve visual identity; do not regenerate a different mark from text or accidentally use the simplified mini logos in some UI mockups as the new master.

The supplied enlarged PNG is interpolated, NOT a genuine vector source. Reuse it for appropriate raster contexts; for small icons use the artwork carefully or trace an editable SVG only if fidelity can be reviewed by the human. Never claim an automatic upscale is a new native-resolution vector. If changing logo asset files requires explicit brand approval, ask first.

- Sage `#CFE7C1` for soft support/neutral tinted blocks.

Use subtle amber only for alerts/achievement highlights and semantic error/red only for errors. Light and dark palettes MUST be designed as distinct accessible token sets (not filter inversion). A System choice should follow OS changes; persist only harmless theme preference. Avoid giant saturated gradients, green-on-green low contrast and unnecessary background illustrations.

Apply logo at sensible sizes to `Wordmark`/`AppHeader` and dashboard header, plus an appropriate simplified mark for favicon/PWA ONLY after review. Avoid `background-image` where accessible branding semantics matter.
